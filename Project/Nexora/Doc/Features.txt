# 🚀 Nexora Project – Updated Features List (Post Permission Changes)

## 👑 Admin Features
- Manage all users, products, categories, brands, orders, coupons
- Full CRUD on:
  - Categories
  - Brands
  - Products (any seller)
  - Orders (any customer or seller)
  - Coupons/Discounts
- Approve/reject sellers (if workflow present)
- Access all payments/transactions
- View platform-wide analytics
- Access Django admin panel

## 🛒 Seller Features
- Add/Edit/Delete **own products only**
- View and manage own product inventory
- See orders containing their products (cannot see others’ orders)
- Update product details (stock, price, description) for their products
- View sales reports for their products

## 👤 Customer Features
- Register, login, manage their profile
- Browse products/catalog
- Search, filter, and view product details
- Add products to cart & wishlist
- **Checkout restricted to customers only**
- Place orders and make payments
- View their own order history
- Apply coupons during checkout

## 💳 Payments
- Simulated payment API (with transaction ID)
- Payment status linked to orders

## 📝 Order Management
- Customers see their own orders
- Sellers see orders containing their products only
- Admin sees all orders, can update any order status

## 🎁 Coupons & Discounts
- Admin can create/manage coupons
- Customers can apply coupons during checkout

## 💖 Wishlist
- Customers can add/remove products to/from wishlist

## 📑 API Documentation
- Swagger & Redoc auto-generated docs for all endpoints

## 🛡️ Security & Rate Limiting
- Strong password validation
- JWT-based authentication & refresh
- Rate limiting for sensitive endpoints (e.g., registration)
- Logging & error tracking

## 🚚 Deployment Ready
- MySQL integration
- Config notes for Docker/AWS/Gunicorn/Nginx/HTTPS

---

### 🔒 **Role-Based Protection (Post-Fixes)**
- **Admin**: Full control everywhere
- **Seller**: Only own products + orders with own products
- **Customer**: Shopping flow & own orders only
- **No role mixing, no privilege leakage**

---

### 🟢 **Multi-vendor E-commerce Logic:**
- Sellers operate independently
- Admin controls global settings
- Customers have protected shopping experience
